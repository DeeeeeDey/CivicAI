# CivicAI Multimodal Engine

This is the FastAPI PyTorch microservice powering CivicAI's image classification and severity detection. 
It uses OpenAI's CLIP model for zero-shot image-text vector embeddings.

Automatically built and deployed on Hugging Face Spaces using the Docker SDK.
